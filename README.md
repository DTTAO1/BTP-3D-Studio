# BTP 3D Studio v2.0.0

**IA BTP et contrôle qualité**

## Capacités actives
- Interface premium responsive
- Calibration par 2 points
- Reconnaissance BTP enrichie
- Paramètres contextuels
- Modèle 3D constructif
- Métrés et contrôle quantités
- IFC/BIM enrichi
- Phasage 4D simplifié
- Estimation de prix
- Assistant IA local + QA

## Démarrage Windows
1. `INSTALLER_WINDOWS.bat`
2. `LANCER_BTP3D.bat`
3. Ouvrir http://127.0.0.1:8000

## Formats
PDF / DXF / DWG (DWG natif dépend du convertisseur installé), exports Excel / CSV / JSON / OBJ / IFC / HTML.

## Validation
Tests moteur, API et UX inclus dans `tests/`.
